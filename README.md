# 🌱 MindBloom

A lightweight pop-up app for everyday emotional friction: the gap between doing nothing and seeking clinical help.

## The problem
Most people deal with small, daily stress that builds up. Therapy is expensive and has long waitlists; "too small for help" keeps people from asking, and social media often makes it worse. There's also no easy way to track how you're doing.

## Our solution
We wanted something that fills the gap between doing nothing and seeking clinical help, and we wanted it to feel light and rewarding instead of like another heavy app to manage. So we built a small pop-up where every self-care action waters a tree that grows as you do.

## Features

- 🌳 Growing tree (Sprout → Seedling → Sapling → Grown); each self-care activity earns a bucket of wate; 3 self-care actions = next stage
- 😊 Daily mood log: A quick daily check-in that tracks how you’re feeling over time.
- 📓 Journal with a simple template (appreciations, one thing to improve, affirmation) and a free-form diary. [edit: add voice notes only if they work]
- 🌬️ Guided breathing: An inhale/hold/exhale animation with calming text.
- 🐿️ AI chat companion powered by Gemini: Bloom, a cute squirrel chat that chats with you as a friend, gives affirmations, helps organize your thoughts, and suggests ways to feel better.

## Accomplishments that we are proud of
- Turning an idea into a working, polished app within the hackathon
- A tree that visibly grows from real self-care actions, making progress feel tangible
- A design that feels calm instead of clinical
- An app that will actually improve personal well-being


## What I learned
- How to take a Figma design into working code, and how Next.js projects are structured
- How to connect and prompt an AI model for a sensitive use case
- The small design choices, like the tree, a squirrel mascot, and a pop-up instead of a full app
- Teamwork, communication skills, time management

  
## Tech stack
Next.js, React, Tailwind CSS, Gemini API

We started by putting our idea into Figma to design and generate the base of the app: the layout, the pop-up window, and the first versions of the tree, mood log, journal, and breathing screens. Then we exported the project as code (Next.js, React, and Tailwind CSS), pulled it into VS Code through GitHub, and built on top of it with our own new ideas (AI chat box character, Gemini, journal templates, buckets or water) to turn it into MindBloom.
